復元処理は `importData` で行い、読み込んだデータを `normalizeTask` / `normalizeArchiveRecord` で整えてから `mergeById` に渡します。
重複の判定は `id` だけで、`importData` は現在のタスク一覧と履歴（アーカイブ）の両方の `id` を1つの `knownIds` セットにまとめます。
`mergeById` はこのセットにない `id` のデータだけを追加し、追加した `id` をセットに加えるので、タスク側で追加された `id` が履歴側でもう一度追加されることはありません。
ただし判定はリストごとにまとめて行うため、同じリストの中に同じ `id` が2件あると両方とも追加されます。
