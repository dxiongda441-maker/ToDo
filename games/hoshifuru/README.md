# ほしふるクエスト

**星をうばわれた世界で、3 つの「ほしのしずく」を集める旅。** 魔物と戦って経験値をため、レベルを上げて強くなる、
昔ながらのドット絵ロールプレイングゲームです。`index.html` をブラウザで開くだけで遊べます（インストール不要・ネット接続不要）。

絵・曲・効果音・マップはすべてこのフォルダの JavaScript がその場で作ります（画像や音のファイルはありません）。
字のフォント（DotGothic16）だけはネットから読みますが、つながらなくても別の字で遊べます。

## 遊び方

| 操作 | キーボード | スマホ |
| --- | --- | --- |
| 移動・選択 | 矢印キー / WASD | 画面下の十字ボタン（「せってい」→「がめんの ボタン」でパソコンでも出せる） |
| 決定・はなす・しらべる | Z / Enter / スペース | A |
| キャンセル・メニュー | X / Esc | B |

- 人の前で決定すると話す。店・宿屋はカウンターごしでも話せる。宝箱・台・家の中の **つぼ** の前で決定すると調べる（つぼには小さな物が入っていることがある）。
- フィールドで B（キャンセル）を押すとメニュー：じゅもん・どうぐ・そうび・つよさ・ちず・きろく・はなす・せってい。
- **はなす**：仲間と話す。いる場所や旅の進み具合で、ルナとミントの言うことが変わる（会話は `data.js` の `partyTalk`）。
- 迷ったら **ちず**：世界の全体と、いまいる所、つぎに行くとよい所（ヒントの文つき）が分かる。
- **冒険の書**（セーブ）は、教会で「きろくする」・宿屋に泊まる・戦闘のあと・場所を移ったときに自動で残る。
- 全滅しても、お金が半分になって最後に寄った町の教会から再開できる（経験値やレベルは減らない）。
- 「せってい」→「むずかしさ」を **かんたん** にすると、経験値とお金が 1.5 倍になり、全滅してもお金が減らない（いつでも切りかえられる）。

## 旅の流れ

1. **ソラの村** から出発。村のまわりで力をつけ、北の **ほらあな** の奥で 1 つめのしずく。
2. しずくの光で川の結界がとけ、**港町マリン** へ。魔法使い **ルナ** が仲間になる。**風の塔** で 2 つめ。
3. 北の山の結界がとけ、**森の村リーフ** へ。僧侶 **ミント** が仲間になる。**湖の神殿** で 3 つめ。
4. 湖に光の橋がかかり、**かげの城** へ。かげの王をたおして空に星をとりもどす。
5. **クリア後**：ソラの村に星のせいれいが現れ、おまけのダンジョン **星の遺跡** へ連れていってくれる。
   最奥の **ほしくい** は、最大レベル（30）でも勝率 3〜5 割ほどの強敵（がんばりのたねや さくせんが 鍵）。

## より道

- **とうぎじょう**（港町マリン・右の兵士）：3 回つづけて戦う勝ちぬき戦。ランクはブロンズ → シルバー → ゴールド → ほし（クリア後）。
  はじめて勝つと特別な装備（てつのたて・はがねのつるぎ・ひかりのつるぎ・ゆうしゃのたて）、2 回目からは賞金。
  負けても全滅にはならず、お金も減らない。ランクごとの「めやす」のレベルは、自動プレイで 9 割ほど勝てるレベル。
- **まものはかせ**（港町マリン・左のおじいさん）：ずかんに 8・16・24 種類、そして全部のせると、まほうのみず・ふっかつのはね・
  がんばりのたねをくれる。

## 強くなる手ごたえ

- **レベルアップ**：上がった能力が一つずつ表示され、決まったレベルで新しいじゅもんを覚える。
- **弱い魔物がにげる**：ずっと強くなると、前の場所の魔物は「おそれをなして にげだす」。
- **きろく → ぼうけん にっし**：旅立ち・仲間・ボス・しずく・5 レベルごとの成長（そのときの HP と攻撃力）・覚えたじゅもんが、
  プレイ時間と一緒に残る。あとから読み返すと、どれだけ強くなったかが分かる。
- **きろく → まもの ずかん**：出会った魔物の絵。たおすと HP・経験値・弱点などが分かる。
- **ToDo との連動**：ToDo アプリでタスクを完了したり、集中タイマーで集中しきったりすると、町に入ったときに **がんばりのたね**（1 日 5 個まで）がもらえる。
  使うと能力が 1 つ上がる。現実のがんばりが、ゲームの中の強さになる。

## 仲間とじゅもん

| 仲間 | 得意なこと | おもなじゅもん（覚えるレベル） |
| --- | --- | --- |
| ゆうしゃ（主人公） | 力も守りも高い。回復も少しできる | いやし 3・ひのこ 4・にげみち 8・ふるさと 10・だいいやし 14・いかずち 18・ほしのひかり 24 |
| 魔法使い ルナ | 攻撃じゅもん | ひのこ 1・ねむりのうた 3・こおりのつぶて 6・ちからのまほう 9・ほのおのうず 13・ばくはつ 19 |
| 僧侶 ミント | 回復と守り | いやし 1・どくけし 2・まもりのいのり 3・ひかりのや 5・いやしのひかり 7・だいいやし 9・よみがえり 11 |

戦闘では一人ずつ命令するほか、「おまかせ」で自動にもできる。おまかせの **さくせん** は、バッチリがんばれ（ふつう）・ガンガンいこうぜ（MP を気にせず攻める）・いのちだいじに（早めに回復、仲間にもやくそう）・じゅもんせつやく（回復いがいのじゅもんを使わない）から選べる。

## 難しさ（自動プレイでの目安）

`node tools/hoshifuru-balance.js [seed]` は「その場所で戦う → 傷ついたら宿で休む → 買える一番いい装備を買う」をくり返し、
ボスに 6 割以上勝てるようになったら先へ進む、ふつうの遊び方をまねた自動プレイです（命令は「おまかせ」と同じ）。

| 段階 | レベル（seed 1） | 戦闘回数 | ボスの勝率 |
| --- | --- | --- | --- |
| ソラの村まわり | 3 | 8 | － |
| 北のほらあな（いわおとこ） | 6 | 20 | 83% |
| 港町・風の塔（あらしのおおとり） | 14 / 14 | 60 | 90% |
| 森の村・湖の神殿（みずのおおへび） | 17 / 17 / 16 | 20 | 60% |
| かげの城（やみのもんばん・かげの王） | 24 / 23 / 23 | 10 | 100% |
| 星の遺跡（ほしくい・おまけ） | 30 / 30 / 30 | 13 | 52%（seed 2・3 では 53%・27%） |

クリアまでの戦闘はおよそ 130〜140 回。人が遊ぶと、宝箱を探したりじゅもんを考えて使ったりするぶん、もう少し楽になる。

## 保存データ

| localStorage のキー | 中身 |
| --- | --- |
| `hoshifuru.save.v1` | 冒険の書（仲間・持ち物・お金・場所・フラグ・宝箱・記録・ずかん・日誌・がんばりのたねの受け取り済み ID） |
| `hoshifuru.settings.v1` | 設定（メッセージの速さ・音・画面のボタン・むずかしさ） |

ToDo の `todo.tasks.v1`・`todo.archive.v1`・`todo.focus.v1` は **読むだけ** で、書きかえない。
冒険の書に項目を足すときは、`game.js` の `loadSave()` で古い冒険の書にも足す（例：`journal`）。

## ファイル

| ファイル | 中身 |
| --- | --- |
| `data.js` | 職業・じゅもん・どうぐ・装備・魔物・魔物の特技・出現表（数字を変えるのは ここ） |
| `rules.js` | 成長・ダメージ・戦闘の進め方・「おまかせ」の考え方（画面を触らない。Node でも動く） |
| `maps.js` | 世界地図・町・ダンジョン・人・宝箱・ボス・できごと・店 |
| `sprites.js` | 人・魔物・地形のドット絵（文字の並びで描いて canvas にする） |
| `audio.js` | 曲（MML で書く）と効果音（Web Audio でその場で鳴らす） |
| `game.js` | 画面・入力・メッセージ・メニュー・歩く・戦闘の画面・セーブ |

読み込み順は `data → rules → maps → sprites → audio → game`（`index.html`）。

## 変えたら確かめること

```sh
bash tools/check.sh                       # マップの形・行き来できるか・データの参照・ルール・曲（Node）
node tools/hoshifuru-balance.js 1         # 数字を変えたら：詰まる所・稼ぎすぎの所がないか（seed を変えて何回か）
NODE_PATH="$(npm root -g)" node tools/hoshifuru-playtest.js   # 本物の画面をキー操作で最初から最後まで（20〜30 分）
```

`hoshifuru-playtest.js` は、道を探して歩き、店・宿屋・仲間・ボス・エンディング・つづきから・星の遺跡までを確かめる。
戦闘はテスト用の「自動の命令」、レベルはテスト用に上げる（`game.js` の `HF.debug`）。
