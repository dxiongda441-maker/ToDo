# うつろい（UTSUROI）

**駒の動きは「床」が決める。床は、駒が離れるたびに移ろう。**

2 人で遊ぶ、運の要素がない盤上戦略ゲームです。`index.html` をブラウザで開くだけで遊べます（インストール不要・ネット接続不要）。CPU との対戦（3 段階）と、1 台の端末を交代で使う 2 人対戦ができます。

## ルール（1 分で読めます）

### 盤と駒

- 7×7 の盤。各マスの床に **紋** が描かれています。
- 駒は **石**（6 枚）と **王**（1 枚）の 2 種類だけ。先手は黒（下側）、後手は白（上側）。

### 動き方：床の紋のとおりに動く

| 紋 | 動き |
| --- | --- |
| 十（じゅう） | 縦横に 1 マス |
| 斜（しゃ） | 斜めに 1 マス |
| 跳（ちょう） | 桂馬の形に跳ぶ（8 方向・間の駒は飛び越える） |
| 走（そう） | 縦横にどこまでも（駒は飛び越えない） |

- **王** だけは床に関係なく、周囲 8 マスに 1 歩。
- 相手の駒がいるマスに動けば、その駒を取れます（取るかどうかは自由）。

### 床は移ろう

駒がマスを **離れると**、そのマスの紋が 1 段階変わります。

```
十 → 斜 → 跳 → 走 → 十 → …
```

強い「走」から離れると弱い「十」に戻り、「跳」から離れると強い「走」が生まれます。自分の離れた床を次に使うのは相手かもしれません。

### 勝ち方

1. 相手の **王を取る**
2. 自分の王を相手の **玉座**（相手の王が最初にいたマス）に進める
3. 相手の番に、相手が 1 手も指せない

両者あわせて 100 手に達したら、取られた駒が少ない方の勝ち。同じなら引き分け。

## 「誰でも平等に」のための工夫

| 工夫 | ねらい |
| --- | --- |
| 盤は毎回ランダム、ただし **点対称** | 先手と後手の条件は完全に同じ。毎回ちがう盤なので **定跡の暗記が効かない**。経験の差より、その場で読む力の勝負になる |
| **入れ替えルール**（パイ・ルール） | 先手の 1 手目を見て、後手は先手側と入れ替われる。先手は「入れ替えられても困らない、ほどよい手」を指す必要があり、先手の有利が消える |
| 駒は 2 種類だけ | 覚えることは床の 4 種類だけ。動き方は盤に描いてある |
| 運の要素なし・情報はすべて見える | 勝敗は実力だけで決まる |
| 色だけに頼らない表示 | 床は形（＋ × ・ 矢印）と漢字でも区別できる。黒と白の駒は明るさで区別 |
| 初心者向けの補助 | 動ける先の表示、取られそうな駒・取れる駒の表示、ヒント、待った |
| 盤面コード | 同じコードで同じ盤が作れる。離れた友だちと同じ盤で腕比べもできる |
| **駒落ち**（ハンデ） | 実力差があるとき、強い方の石を 1〜3 枚減らして始められる。初心者と経験者、親子でもいい勝負にできる（駒落ちのときは入れ替えルールは使わない） |

## ルールの決め方（CPU 同士の対局で確かめた）

最初の案（王も床に従い、相手の最奥列に着けば勝ち）は、王が「走」の床に乗って一気に駆け抜けられるため、**20 盤中 9 盤で先手が 1 手目から必勝**でした。そこで勝ち方と王の動きを変えた 4 案を、強い CPU 同士で 40 局ずつ対局させて比べました。

| 案 | 先手勝ち | 後手勝ち | 引き分け | 手数（中央値） |
| --- | --- | --- | --- | --- |
| 王も床に従う・玉座に着いたら勝ち | 23 | 17 | 0 | 45 |
| 王も床に従う・到達勝ちなし | 16 | 14 | 10 | 78 |
| **王は周囲 1 歩・玉座に着いたら勝ち（採用）** | **16** | **18** | **6** | **62** |
| 王は周囲 1 歩・相手の最奥列に着いたら勝ち | 29 | 11 | 0 | 58 |

採用した案をさらに 120 局（合計 160 局）対局させた結果は、先手 78 勝・後手 63 勝・引き分け 19。決着した対局のうち先手の勝ちは約 55% で、わずかな先手有利は入れ替えルールで打ち消せる程度です。

ルールを変えたら `node tools/utsuroi-selfplay.js 40 hard 150` で同じように確かめられます。

## ファイル

| ファイル | 中身 |
| --- | --- |
| `index.html` | 画面の HTML（ルール説明・ダイアログを含む） |
| `style.css` | 見た目（明るい配色と暗い配色の両方） |
| `engine.js` | ルールと CPU。画面に依存しないので Node でも動く（テストは `tools/test-utsuroi.js`） |
| `ui.js` | 盤の描画と操作、CPU の呼び出し（Web Worker）、対局の保存 |

### CPU のしくみ

アルファベータ探索（反復深化・置換表・静止探索・キラー手）。評価は「石の数」「乗っている床の強さ」「動ける手の数」「取れる駒の数」「王の前進」。

CPU は入れ替えルールにも対応しています。後手の CPU は、先手の 1 手目が強すぎると判断したら入れ替えます（自己対局では、先手が最善手を指すと 10 局中 10 局で入れ替え、適当な手なら 10 局中 3 局）。

| 強さ | 読み | 特徴 |
| --- | --- | --- |
| やさしい | 1 手 | 評価に大きなゆらぎを入れて、ときどき悪い手を指す |
| ふつう | 3 手 | 小さなゆらぎ |
| つよい | 1.5 秒で読めるところまで（多くの局面で 8〜10 手） | ゆらぎなし |

どの強さでも「1 手で勝てる手」と「1 手で負ける手」は見逃しません。

CPU 同士の対局（先後を交互に）では、ふつう が やさしい に 39 勝 1 敗、つよい が ふつう に 23 勝 1 敗で、段階ははっきり分かれています。

### 保存されるデータ（localStorage）

| キー | 中身 |
| --- | --- |
| `utsuroi.game.v1` | 対局中の盤（盤面コードと指した手）。再読み込みしても続きから遊べる |
| `utsuroi.settings.v1` | 最後に選んだ対局の設定 |
| `utsuroi.record.v1` | CPU との戦績（駒落ちの対局は記録しない） |
| `utsuroi.seenRules.v1` | 最初のルール説明を表示したかどうか |
