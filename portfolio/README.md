# つみあげ帳（非公開ポートフォリオサイト）

家計簿・収支ダッシュボード・相場分析・ノート・日々の振り返りをまとめた、自分専用のサイトです。
本番は claude.ai の非公開ページ（Artifact）で動いていて、記録はそのページのデータベースに保存されています。

このフォルダには **画面のコードと架空のサンプルデータだけ** を置いています。
本物の家計簿データ（金額・お店・借入など）は、このリポジトリが公開設定のため入れていません。

## ファイル

| ファイル | 中身 |
|---|---|
| `site.html` | claude.ai に公開しているページのソース（そのまま貼り付けて公開する形式） |
| `dev/sample-data.json` | 画面確認用の架空データ（家計簿144件・投稿3件） |
| `dev/build-preview.mjs` | `site.html` とサンプルデータからローカル確認用の `dev/preview.html` を作るスクリプト |

## ローカルで画面を確認する

```sh
node portfolio/dev/build-preview.mjs
# → portfolio/dev/preview.html をブラウザで開く
```

依存パッケージはありません（Node.js だけで動きます）。
プレビューでは claude.ai の機能（データベース・写真の読み取り・Google ドライブ書き出し）の代わりに、
メモリ上の仮データベースを使います。保存した内容はページを閉じると消えます。

## 変更を本番に反映する流れ

1. `site.html` を編集して、プレビューで確認する
2. ブランチに push する
3. Claude Code のセッションで「GitHub の site.html を本番に反映して」と頼む
   （claude.ai の非公開ページへの公開は Claude からしかできません）

## 守ること

- 本物の家計簿データ・借入の情報・カード番号・口座番号・残高をこのリポジトリに入れない
- `dev/sample-data.json` のデータは架空のものだけにする
