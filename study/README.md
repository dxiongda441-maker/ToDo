# まなびログ（学習アプリ）

理解度に合わせて問題を出し、**理解度**と**定着度**を数値で確認できる学習アプリです。
科目は「基本情報技術者試験（FE）」「Python」「ワイン」「日常英会話」の 4 つ。

- 問題形式: 選択 → 穴埋め → 白紙（記述）→ コード（Python）と、理解度に合わせて自動で変わる
- 診断テスト: 全分野から同じ数ずつ出題して、分野別に「得意 / 要復習 / 苦手」を判定（FE は 9 分野 × 3 問）
- Python は「基礎知識 → コードを読む → コードを選ぶ → コードを書く → eval」の順に段階的に進む
- 問題ごとに前回の結果を表示し、間違えた問題は時間をおいて再出題
- 数値化: トピックごとの理解度（0〜100）、定着度（%）、FE の予想正答率、実力テストの点数
- 計画: 期限のある目標（FE 合格など）は試験日から逆算、目標がまだないもの（ワイン・英会話）は幅広く基礎から。目標は後から設定できる
- AI（任意）: Claude の API キーを登録すると、理解度に合わせて新しい問題を作り、記述式を採点・添削する
- データ: ブラウザに保存。バージョン番号付きで、アプリ更新時は自動で移行。JSON でバックアップ・復元できる

操作方法はアプリ内の「使い方」ページ（ホームの「使い方」リンク）にまとめています。設計の詳細は [`../docs/DESIGN.md`](../docs/DESIGN.md) を参照。

## 使い方

ビルドは不要です。このフォルダを静的ファイルとして配信して、ブラウザで開きます。

```bash
cd study
npm start            # http://localhost:8080 で起動（npx http-server）
```

`index.html` を直接ダブルクリックで開くと ES モジュールが読み込めないので、必ずローカルサーバー経由で開いてください。
GitHub Pages や Netlify などに `study/` を置けば、そのまま他の人にも使ってもらえます。

### AI を使う場合

1. [Anthropic Console](https://console.anthropic.com/) で API キーを発行
2. アプリの「設定」で「AI を使う」をオンにしてキーを入力 →「接続テスト」
3. 学習画面の「出題元」で「おまかせ」か「AI が新しく作る」を選ぶ

キーはそのブラウザの中にだけ保存され、バックアップには含まれません。利用料はキーの持ち主に請求されます。

## 開発

```bash
cd study
npm test             # ロジック・問題バンク・移行のテスト（Node 22 以上、python3 が必要）
```

- 問題を追加する: `src/content/<科目>.js` に追記して `npm test`。Python の選択問題は実際にコードを実行して正解を検証し、コード問題は模範解答がテストに合格するか確認する
- 科目を追加する: `src/content/` にファイルを作り、`src/content/index.js` に登録する
- セーブデータの形を変える: `src/migrations.js` の手順に従って `SCHEMA_VERSION` を上げ、移行関数とテストを追加する
